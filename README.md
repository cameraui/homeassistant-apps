# camera.ui Apps for Home Assistant

Run [camera.ui](https://github.com/cameraui/camera.ui) directly on Home Assistant OS.

[![Add repository to my Home Assistant](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fcameraui%2Fhomeassistant-apps)

## Apps

- **camera.ui** — self-hosted NVR and camera management with live streaming, recordings, object detection and smart home integrations.

## Installation

1. Add this repository in Home Assistant (use the button above, or add it manually under Settings → Apps).
2. Install the camera.ui app.
3. Start it and open the web UI. The first start downloads the camera.ui server and takes a few minutes.

See the app documentation for configuration and hardware acceleration details.
